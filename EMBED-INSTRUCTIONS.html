Podcast Quote Widget — Embed Guide

Two ways to add the quote builder to the Straw Hut services page.

Option A: iframe Embed Easiest

Host embed.html anywhere (GitHub Pages, your own server, CDN) and embed it with a single line. No conflicts with your existing site CSS or JS.

<!-- Straw Hut Podcast Quote Builder --> <iframe src="https://strawhutmedia.github.io/Sales-Quoting/embed.html" width="100%" height="700" frameborder="0" style="border:none; max-width:600px; display:block; margin:0 auto;" ></iframe>

Note: Update the src URL to wherever you host embed.html. If using GitHub Pages, the URL will be https://strawhutmedia.github.io/Sales-Quoting/embed.html

Option B: Direct Embed (Inline) No iframe

Drop this directly into the services page HTML. The widget renders inline — no iframe needed. All styles are scoped to #shm-quote-widget so they won't conflict with the rest of the page.

<!-- Straw Hut Podcast Quote Builder — paste this where you want the widget --> <div id="shm-quote-widget"></div> <script src="https://strawhutmedia.github.io/Sales-Quoting/widget.js"></script>

That's it — two lines. The script auto-initializes, injects its own scoped styles, and builds the entire widget inside the div.

Setup: Enable GitHub Pages (one-time)

To get the public URL for hosting, enable GitHub Pages on the repo:

  1. Go to github.com/strawhutmedia/Sales-Quoting
  2. Click Settings (top tab bar)
  3. In the left sidebar, click Pages
  4. Under Source, select the branch: claude/podcast-quote-widget-TNvH2 (or main after merge)
  5. Set folder to / (root)
  6. Click Save
  7. Wait 1–2 minutes. Your URL will be: https://strawhutmedia.github.io/Sales-Quoting/
