Developer Integration Guide

Straw Hut Media — Podcast Packages Page + Custom Quote Builder Widget
Target platform: ASP.NET  |  Dependencies: None (Calendly widget loaded dynamically)

Architecture Overview

This repo contains two things that need to go on the Straw Hut website:

ComponentFile(s)What it does
Packages Page index.html 3 package cards (Essential / Premium / Ultimate) + "Build Your Custom Package" CTA. Each card's "Get Started" button opens a Calendly popup with the package details pre-filled.
Quote Widget widget.js Self-contained quiz (8 steps). Calculates a custom price and feature list. "Schedule a Call" CTA opens Calendly with all quiz answers pre-filled.
How it works: When a visitor clicks any "Get Started" button (on packages or quiz), it opens a Calendly popup for a 15-minute discovery call. All selections (package name or quiz answers) are automatically injected into a custom Calendly field so the team receives the details in the calendar invite and email.

Option A: Full Page Integration Recommended

Copy the packages page content into an ASP.NET view/page. This gives you the 3 package cards + custom quote builder all on one page.

Step 1 — Copy widget.js to your static files

Place widget.js in your scripts directory, e.g.:

/Content/scripts/widget.js — or — /wwwroot/js/widget.js — or wherever your ASP.NET project serves static JS from

Step 2 — Create the page

Create a new view/page (e.g. Packages.cshtml or Packages.aspx). Copy the HTML content from index.html into your site's layout. Specifically, you need:

  1. The CSS — Everything inside the <style> tag in index.html. Add this to your site's stylesheet or keep it in a <style> block on the page.
  2. The HTML — The two main <div> sections:
    • <div id="packages-view"> ... </div> — the 3 package cards + custom CTA
    • <div id="quiz-view"> ... </div> — the quiz container
  3. The scripts — The widget.js reference + the inline <script> block at the bottom

Step 3 — Update the script path

In the copied HTML, update the widget.js path to match where you placed it:

<!-- Update this path to match your ASP.NET static file location --> <script src="~/Content/scripts/widget.js"></script> <!-- Or if using ASP.NET Core: --> <script src="/js/widget.js"></script>

Step 4 — Done!

That's it. The widget and Calendly integration are fully self-contained. No npm packages, no build step, no API keys.

Option B: Quiz Widget Only

If you only want the custom quote builder (no package cards), it's just two lines:

<!-- Paste this wherever you want the quiz widget to appear --> <div id="shm-quote-widget"></div> <script src="~/Content/scripts/widget.js"></script>

The widget auto-initializes, injects its own scoped CSS (all prefixed with #shm-quote-widget), and won't conflict with existing page styles. Max width is 560px, centered by default.

Calendly Configuration

The Calendly integration is already wired up. Here's what's configured:

SettingValueWhere

Custom Question "Tell us about your project!" (multi-line text, Question 1) Configured in Calendly event settings under Invitee Questions
Data passed Mapped to a1 (first custom answer) Auto-filled via Calendly popup prefill API
Important: If the Calendly URL ever changes, update it in two places:
1. widget.js — line 81: var CALENDLY_URL = '...';
2. index.html (your ASP.NET page) — the inline script near the bottom: var CALENDLY_URL = '...';

Google Fonts Dependency

The page uses the Inter font. If your site doesn't already load it, add this to your <head>:

<link rel="preconnect" href="https://fonts.googleapis.com"> <link rel="preconnect" href="https://fonts.gstatic.com" crossorigin> <link href="https://fonts.googleapis.com/css2?family=Inter:wght@400;500;600;700;800;900&display=swap" rel="stylesheet">

If your site uses a different font, the widget will fall back to the system font stack gracefully.
